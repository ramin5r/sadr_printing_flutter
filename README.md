# Sadr Printing Flutter Simple

A simple beginner-friendly Flutter conversion of the uploaded Persian RTL HTML pages.

## Files

- `lib/main.dart`
- `lib/database_helper.dart`
- `lib/customer_model.dart`
- `lib/order_model.dart`
- `lib/home_screen.dart`
- `lib/add_order_screen.dart`
- `lib/customers_screen.dart`
- `lib/order_details_screen.dart`

## Run

```bash
flutter pub get
flutter run
```

The app uses `sqflite` for local SQLite storage.
